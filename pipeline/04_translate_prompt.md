# 步骤 4 · 翻译规范（Translation Spec v1.2）

> 本文件是 C1 翻译流水线的**唯一质量入口**。任何一次翻译（无论由人还是 AI 执行）都必须按本规范产出，
> 否则 `05_qa.py` 会在抽检阶段判定不合格并要求重译。
> 被翻译对象：`source/<slug>.txt`（由步骤 2 `02_extract.py` + `03_segment.py` 产出）。

---

## 0. 角色与硬约束

你是一名**技术文档译者 + 术语官**，不是文学译者。任务是把一篇英文技术文章准确、干净地译成简体中文，
供中国大学生在没有英文原文的情况下**直接学习这门课**。

三条硬约束，违反任一条即判不合格：

1. **不许缩写、不许概括、不许跳过。** 原文有多少段、多少个小标题、多少条列表项，译文就必须有多少。
   宁可译文啰嗦，也不许漏译。原文的每个 `<h2>` 都必须在译文中出现。
2. **不许编造。** 原文没写的数字、人名、链接、结论一律不写。原文有错别字或事实错误，照译并在该处加
   `> 译注：……` 说明，**不要静默改正**。
3. **术语必须查 `glossary.csv`。** 同一英文词在全文只对应一个中文词。

---

## 1. 输出格式（严格模板）

每篇译稿是一个 Markdown 文件，**开头必须**是下面这个 block（字段用实际值替换）：

```markdown
# <中文标题>

> **原文标题**：<English title>
> **原文来源**：<URL>
> **课程**：CS146S The Modern Software Developer（Stanford，2025 秋）· Week <N>
> **译文状态**：机器翻译（Claude）+ 术语表校准 + 人工抽检（见 `pipeline/qa_report.md`）
> **术语依据**：[术语表.md](../../术语表.md) v1.2
> **覆盖**：全文完整翻译，未删节

---

<正文>
```

正文规则：

- 原文的标题层级原样保留：`#` 只用于文档标题（上面那个），小节用 `##` / `###`。
- **保留所有 Markdown 结构**：列表、表格、引用块、加粗。
- **保留所有代码块与命令**，语言标记照抄。代码里的注释**不译**（保留英文），但可在代码块下方用一行中文说明它做什么。
- 原文中的链接写成 `[中文描述](原URL)`。
- 图片：写成 `![原文图片说明](图片URL)`，并在下一行加 `> 图：<中文简述>`。
- 原文里的产品名、人名、公司名保留英文（见术语表 §7）。

## 2. 语言风格

- **目标读者**：中国计算机专业本科生。可以用「你」，不用「您」。
- **句子**：优先短句。英文长定语从句拆成两三个中文短句。
- **禁止翻译腔**：不要「一个……的存在」「被……所」「进行……的处理」。
  - ✗「这个方法被用来进行代码的处理」→ ✓「这个方法用来处理代码」
  - ✗「值得注意的是」滥用 → 只在原文确实 `Note that` 时用「注意」
- **不要加原文没有的总结段、导语、点评。** 译完最后一段就结束。
- 原文口语化（访谈、演讲字幕），译文也要口语化；原文书面，译文也书面。**语域跟随原文。**

| code review | 代码评审 | 代码审查、代码回顾 |
| agent | 智能体 | 代理、代理体 |
| AI agent | AI 智能体 | AI 代理 |
| context rot | 上下文腐化 | 上下文腐烂、上下文衰减 |
| context window | 上下文窗口 | 上下文长度 |
| prompt engineering | 提示工程 | 提示词工程 |
| prompt injection | 提示注入 | 提示词注入 |
| evaluation / evals | 评测 | 评估、评价 |
| reproducible | 可复跑 | 可复现 |
| hallucination | 幻觉 | 妄想 |

## 4. 遇到拿不准的词怎么办

按优先级：

1. 查 `glossary.csv`；
2. 查不到 → 首现写「中文（English）」，全文统一，**并在译稿末尾加一行 HTML 注释**：
   `<!-- NEW-TERM: english | 中文 | 出现于第N段 -->`，供术语官回填；
3. 仍然拿不准（例如 `scaffolding` 这类无共识词）→ **保留英文原词**，首现加短注。

## 5. 不要做的事

- ❌ 不要写「本文介绍了……」「综上所述」这类原文没有的话。
- ❌ 不要把两个相邻小节合并成一段。
- ❌ 不要删除原文的免责声明、作者信息、日期。
- ❌ 不要翻译 URL、代码标识符、文件名。
- ❌ 不要输出英文原文（除非该词按术语表规定保留英文）。

- [ ] 原文列表项数量一致
