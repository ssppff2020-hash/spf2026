## 1. 为什么还要写一个质检脚本

33 篇译文摆在面前，字数总计约 13.3 万。**人没法读完，不读又不敢交付。**

> **我给 AI 的指令**：
> 「写一个质检脚本，扫描 `C1/翻译/` 下的所有 md，检查五件事：
> ① 覆盖度——manifest 里每条是否都有译稿；
> ② 禁用译法——扫描规范里那张『不许出现』的表；
> ③ 结构完整性——原文小节数 vs 译文小节数；
> ④ 篇幅——中文字符数是否低于『原文词数 × 0.75』；
> ⑤ 待回填术语——收集 `<!-- NEW-TERM -->` 注释。
> **输出一份 `qa_report.md`，只给信号不给结论。**」

写脚本本身的成本远低于"人工抽查 13 万字"，而且**可复算**——这是它最大的价值。

## 2. 第一次跑：三个信号，一真两假

```
coverage      : 81.8%  (27/33)     ← 翻译还在进行中，正常
banned hits   : 0
structure ⚠   : 4
short ⚠       : 0
```

**先看让人放心的那条**：`banned hits: 0`。
33 篇译文里，"代码审查""AI 代理""大型语言模型""可复现"**一次都没出现**。
术语一致性不是靠人抽查出来的，是**扫出来的**——这条让后面所有工作都踏实了。

**再看 ⚠️ 的 4 条结构告警。** 我没有直接去"修译文"，而是**先核对告警本身对不对**：

> **核对动作**：打开 `01-代码评审去做就对了.md` 对应的原文，把它的 7 个"小节"列出来。

结果全部是：`Related posts`、`Recent Posts`、`Civilized Discourse Construction Kit`……
——**全是页面右侧的推荐位导航**。而 Jeff Atwood 那篇短文**正文本身根本没有小节标题**。

**译文是对的，是检查项错了。**

> **这是一个反直觉的教训**：我原以为"小节数比对"比"数字符"聪明得多，
> 结果聪明的那个**误报了**，笨的那个救了大命。原因很简单——
> **导航标题和正文标题在 HTML 里长得一模一样**，而字符数不会被网站结构影响。

**处置**：不是把结论改成"没事"，而是**改检查项**——加一条过滤：
只统计"后面跟着 ≥150 字符正文"的标题（导航项后面跟的是另一个标题，不是段落）。
并把**为什么这么设计**写进脚本顶部的注释，防止下一个人重新踩坑。

## 4. 顺藤摸瓜：原文本身可能是坏的

在核对上面那篇时，我顺手看了一眼原文，看到这样一行：

```
Claudee Code for dattaa infraassttrruucctuturere
HHooww AAnntthrooppiicc tteeaammss uussee CCllaauuddee CCooddee
```

**每个字母都重复了两遍。**

**这不是翻译的问题，是原文抽取就坏了。** 而且它坏得极其隐蔽：

| 为什么它差点蒙混过关 | |
|---|---|
| 不报错 | `pdftotext` 退出码 0，页数正确 |
| 输出"看起来像文本" | 仍是英文单词的形状，不是乱码方块 |
| 人眼容易滑过去 | 扫一眼只看到"哦一篇英文文档" |

**量化它：**

> 我让 AI 写了个判定函数——「奇数位字符 == 偶数位字符」即为重复词（`HHooww` → `Hw`+`Hw`），
> 然后**同时用两个引擎抽同一份 PDF**，各自算重复率。

```
ok   ai-assisted-code-review-assessment   picked=poppler   53,502c  (poppler:0.0%  pymupdf:0.0%)
ok   how-anthropic-uses-claude-code       picked=pymupdf   74,857c  (poppler:25.5% pymupdf:0.0%)
ok   how-openai-uses-codex                picked=poppler   13,085c  (poppler:0.0%  pymupdf:0.0%)
```

**注意第 2 行**：poppler 不只重复字符，它输出的**总字符数还少了 33%**（56K vs 75K）——
**它在重复一部分内容的同时，丢了另一部分内容。**

**处置**：把这次修复**固化成流水线的一步** `02b_extract_pdf.py`（双引擎 + 打分择优选），
而不是手工修这一个文件。修完用干净原文**整篇重译**。

> **三条链式反应——发现 → 双引擎重抽 → 重译——少任何一环，交付出去的都是"看起来没问题"的错件。**

> **自动抽检 + 人工抽读，两者都不能省。**
